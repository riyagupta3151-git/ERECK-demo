# Pulse Collective: Club Event Page

Responsive club event page built with HTML, CSS (Flexbox + Grid) and vanilla JavaScript.

## Features
- Sticky navigation with smooth scrolling
- Hero section followed by a 3-card event grid
- Each card: image, category badge, date/time, Register button
- Category filter (All / Technical / Cultural / Sports)
- Registration modal with validation; registrations saved in localStorage
- Registered cards switch to a disabled "Registered" state

## Run locally
Open `index.html` in a browser. No build step.

## Deploy (GitHub Pages)
Repo Settings > Pages > Deploy from branch `main` / root.
